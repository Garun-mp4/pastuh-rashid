# [Имя] — пастух в сёлах Кизляра

Адаптивный одностраничный сайт-портфолио пастуха в сёлах Кизляра и Кизлярского района.

## Что внутри

- `index.html` — главная страница со всеми секциями сайта.
- `privacy.html` — политика конфиденциальности.
- `personal-data.html` — политика обработки персональных данных.
- `css/` — стили, разбитые по назначению.
- `js/` — логика меню, галереи, FAQ, формы и квиза.
- `api/send-telegram.js` — serverless-функция Vercel для отправки заявок в Telegram.
- `icons/` — SVG-иконки в едином минималистичном стиле и `favicon.svg`.
- `images/prompts.txt` — промты для генерации итоговых изображений.
- `images/*.jpg` — временные изображения-заглушки, чтобы сайт сразу открывался без битых ссылок.
- `.env.example` — пример переменных окружения для Telegram.

## Что добавлено в этой версии

- Все эмодзи в карточках заменены на SVG-иконки.
- Добавлена минималистичная SVG-иконка вкладки браузера: `icons/favicon.svg`.
- Добавлены устойчивые стили изображений: `object-fit`, фиксированные пропорции для hero, портрета и галереи.
- Добавлены страницы с юридическими текстами.
- Форма заявки отправляет данные в Telegram-бот через Vercel API.
- Добавлен квиз: пользователь отвечает на несколько вопросов, а в конце заявка отправляется в Telegram.
- Добавлены чекбоксы согласия на обработку персональных данных.

## Как запустить локально

Обычный просмотр без Telegram-отправки:

```bash
open index.html
```

Для проверки serverless-функции локально используйте Vercel CLI:

```bash
npm i -g vercel
vercel dev
```

## Переменные окружения для Vercel

В настройках проекта Vercel добавьте:

```text
TELEGRAM_BOT_TOKEN=токен_вашего_бота
TELEGRAM_CHAT_ID=id_чата_или_пользователя
```

Токен можно получить у BotFather. `TELEGRAM_CHAT_ID` — ID чата, куда бот должен отправлять заявки. Бот должен быть добавлен в этот чат и иметь возможность отправлять сообщения.

## Что заменить перед публикацией

1. `[Имя]` — на реальное имя или безопасный публичный псевдоним.
2. `+7 000 000-00-00`, `tel:+70000000000` и `https://wa.me/70000000000` — на контакты взрослого представителя.
3. `https://t.me/username` — на рабочую ссылку Telegram.
4. `[адрес сайта]`, `[ФИО / наименование ИП или организации]`, `[email или иной контакт оператора]` в `privacy.html` и `personal-data.html`.
5. Заглушки отзывов — на реальные отзывы или оставьте явную пометку, что это примеры.
6. Изображения-заглушки — на реальные или сгенерированные изображения.

## Важно про изображения

В ТЗ указано, что изображения с героем нужно генерировать на основе прикреплённого фото мальчика. В текущем наборе файлов такого фото нет, поэтому в проект добавлены нейтральные временные изображения-заглушки.

Перед публикацией сайта замените:

- `images/hero-pastuh.jpg`
- `images/about-portrait.jpg`
- `images/shepherd-with-herd.jpg`

на реальные или сгенерированные изображения, созданные с согласия законного представителя, если герой несовершеннолетний.

## Юридическое предупреждение

Страницы `privacy.html` и `personal-data.html` — аккуратные шаблоны для небольшого сайта с формой заявки. Перед публикацией их нужно заполнить фактическими данными оператора и, при необходимости, проверить с юристом.

Если сайт собирает персональные данные граждан РФ и размещается на Vercel/использует Telegram, отдельно проверьте требования к локализации баз данных, уведомлению Роскомнадзора, согласию на обработку и возможной трансграничной передаче данных. Этот проект реализует техническую отправку заявки, но не заменяет юридическую проверку.

## Безопасность

- Не публикуйте точный домашний адрес, школу, постоянные маршруты, документы, геометки и личный телефон ребёнка, если он несовершеннолетний.
- Не храните `TELEGRAM_BOT_TOKEN` в клиентском JavaScript, HTML или публичном репозитории.
- Используйте только переменные окружения Vercel.
- Ограничьте доступ к Telegram-чату, куда приходят заявки.
